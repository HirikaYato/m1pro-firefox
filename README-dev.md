# m1pro dev

Community-maintained Firefox build of [`alexdymov/m1pro`](https://github.com/alexdymov/m1pro).

## Build instructions

### Environment

Tested with:

- Node.js `18.20.8`
- npm `10.8.2`

## Prerequisites

Install [Node.js], which includes [Node Package Manager][npm].

## Install dependencies

Recommended install command:

```bash
npm install --legacy-peer-deps --ignore-scripts
